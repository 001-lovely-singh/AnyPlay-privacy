Play RPG Maker games on your phone

Grab a blanket, pick a game folder, and settle in. Any Play is a free Android app for RPG Maker MV and MZ games that works fully offline. No PC needed.

Made for playing, not fiddling

Add games from your storage

Import RPG Maker MV/MZ folders directly, or unpack a .zip. Import runs in the background and you can cancel it.

Your own on-screen gamepad

Move, resize and recolor buttons, undo changes, and reset. Each game keeps its own layout.

Controller and keyboard

Use touch, a physical controller, a keyboard, or the built-in on-screen keyboard.

Cheats from the pause menu

Toggle unlimited HP/MP, TP and gold, or set gold, level, EXP and stats to any value.

Saves handled for you

Saves are written natively and work for both MV and MZ games.

Encrypted assets just work

Files like .rpgmvp and .rpgmvo are handled automatically. After import, everything runs offline.

Which games work

RPG Maker MV/MZFull

The main focus of Any Play.

Unity WebGLBeta

Web builds with index.html and a Build folder.

Godot WebBeta

Web exports with index.html, .wasm and .pck.

Ren'Py WebBeta

Web builds that contain index.html.

PC-only builds (Windows .exe, Wolf RPG, RPG Maker XP/VX/VX Ace) can't run on Android. Any Play tells you clearly when you pick one. Beta engines vary game to game.

Install in four steps

  1. Download the APK from the button below.
  2. If Android asks, allow installs from unknown sources for your browser or file manager.
  3. Open Any Play and tap Add a new game or Unpack a game.
  4. Pick your game folder (or .zip) and start playing.

Any Play does not include any games. Bring your own.
